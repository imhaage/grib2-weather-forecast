GRIB2 Weather forecast

Browser storage: Checking…

This experimental app explores how far browser-based weather visualization can go. GRIB2 forecast files are very large, so downloaded files are cached locally in your browser with IndexedDB to make the next data load instant. Depending on the selected model package, this cache can use several gigabytes of storage.
